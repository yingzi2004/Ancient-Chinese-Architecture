# 🌫️ 香炉烟雾效果使用说明

## 📦 文件清单

已创建以下文件：
1. `IncenseSmokeEffect.cs` - 香炉烟雾效果主脚本
2. `IncenseSmokeEditor.cs` - 编辑器配置助手

---

## 🚀 快速开始

### 方法一：使用编辑器助手（推荐）

1. **打开配置窗口**
   - Unity菜单栏：`工具 → 香炉烟雾效果配置器`

2. **选择香炉对象**
   - 在Hierarchy中选择香炉对象
   - 点击配置窗口中的"从选择获取"按钮

3. **添加烟雾效果**
   - 如果该对象还没有烟雾效果，会显示"添加烟雾效果"按钮
   - 点击按钮自动添加

4. **选择预设**
   - 从下拉菜单中选择合适的预设：
     - `轻烟袅袅` - 淡雅香烟（推荐用于小香炉）
     - `浓烟密布` - 浓重烟雾（大香炉）
     - `檀香` - 檀香专用效果
     - `线香` - 线香效果
     - `柱香` - 柱香效果

5. **点击"应用预设"**

6. **调整效果**（可选）
   - 使用"增强/减弱烟雾"按钮调整强度
   - 使用颜色预设更改烟雾颜色
   - 启用/禁用风力效果

---

### 方法二：手动添加脚本

1. **选择香炉对象** 在Hierarchy中选择香炉GameObject

2. **添加组件**
   - Inspector面板 → `Add Component`
   - 搜索 `Incense Smoke Effect`
   - 点击添加

3. **调整参数**（在Inspector中）
   ```
   烟雾颜色: 设置烟雾颜色和透明度
   烟雾粒子数量: 调整最大粒子数（50-500）
   烟雾上升速度: 调整烟雾上升的快慢
   烟雾扩散范围: 调整烟雾扩散的宽度
   烟雾最小/最大尺寸: 调整粒子大小范围
   烟雾生命周期: 调整粒子存活时间
   烟雾发射速率: 调整每秒发射的粒子数
   启用风力影响: 添加风吹效果
   ```

4. **播放效果** 运行游戏即可看到烟雾效果

---

### 方法三：使用右键菜单

1. 在Hierarchy中右键点击香炉对象
2. 选择：`GameObject → Effects → 添加香炉烟雾效果`
3. 脚本会自动添加并配置

## 🎮 运行时控制

您可以在脚本中使用以下方法控制烟雾：

```csharp
// 获取烟雾组件
IncenseSmokeEffect smoke = GetComponent<IncenseSmokeEffect>();

// 播放烟雾
smoke.PlaySmoke();

// 停止烟雾
smoke.StopSmoke();

// 暂停烟雾
smoke.PauseSmoke();

// 调整烟雾强度（0-1）
smoke.SetSmokeIntensity(0.5f);

// 更改烟雾颜色
smoke.SetSmokeColor(Color.gray);

// 启用风力
smoke.SetWindEnabled(true);
```

## 🎨 参数详解

| 参数 | 范围 | 推荐值 | 说明 |
|------|------|--------|------|
| 烟雾颜色 | Color | 灰白色(0.8, 0.8, 0.8, 0.3) | 烟雾的颜色和透明度 |
| 烟雾粒子数量 | 50-500 | 150-200 | 最大粒子数，影响性能 |
| 烟雾上升速度 | 0.5-5 | 1.0-2.0 | 烟雾上升速度 |
| 烟雾扩散范围 | 0.1-2 | 0.3-0.6 | 烟雾扩散宽度 |
| 烟雾最小尺寸 | 0.1-2 | 0.2-0.5 | 粒子最小尺寸 |
| 烟雾最大尺寸 | 0.5-5 | 1.0-2.0 | 粒子最大尺寸 |
| 烟雾生命周期 | 2-10 | 4-6 | 粒子存活时间（秒） |
| 烟雾发射速率 | 10-100 | 25-50 | 每秒发射粒子数 |

## 💡 使用技巧

### 1. 性能优化
- 移动设备：使用"轻烟袅袅"预设（粒子数少）
- PC设备：可以使用"浓烟密布"预设（粒子数多）
- 多个香炉时，建议降低单个香炉的粒子数

### 2. 视觉效果
- **小香炉**：使用"线香"预设，烟雾细而直
- **大香炉**：使用"柱香"或"浓烟密布"预设
- **檀香**：使用"檀香"预设，带微黄色

### 3. 动态控制示例
```csharp
// 在祭祀场景中，当点燃香时播放烟雾
public class IncenseController : MonoBehaviour
{
    private IncenseSmokeEffect smokeEffect;

    void Start()
    {
        smokeEffect = GetComponent<IncenseSmokeEffect>();
        smokeEffect.StopSmoke(); // 开始时烟雾关闭
    }

    // 当玩家点燃香时调用
    public void LightIncense()
    {
        smokeEffect.PlaySmoke(); // 播放烟雾
        Debug.Log("香已点燃，烟雾升起");
    }

    // 当祭祀完成时调用
    public void ExtinguishIncense()
    {
        smokeEffect.StopSmoke(); // 停止烟雾
        Debug.Log("祭祀完成");
    }
}
```

### 4. 多个烟源
如果香炉有多个插香孔，可以：
1. 创建多个空的子对象作为烟源点
2. 为每个子对象添加`IncenseSmokeEffect`脚本
3. 调整每个烟源的`emissionOffset`参数

### 5. 批量添加
1. 在Hierarchy中选择多个香炉对象
2. 打开配置窗口
3. 点击"为所有选中对象添加烟雾效果"

## 🐛 常见问题

**Q: 看不到烟雾效果？**
A: 检查以下项：
- 确保`playOnAwake`已勾选，或手动调用`PlaySmoke()`
- 检查粒子系统渲染器的排序层级
- 确认场景中有足够的光照
- 检查Camera的Clear Flags设置

**Q: 烟雾太浓/太淡？**
A: 使用配置窗口中的"增强/减弱烟雾"按钮，或调整`emissionRate`参数

**Q: 性能下降？**
A: 降低以下参数：
- `maxParticles` - 减少最大粒子数
- `emissionRate` - 减少发射速率
- `lifetime` - 减少粒子生命周期

**Q: 烟雾方向不对？**
A: 调整以下参数：
- 启用风力效果并调整`windDirection`
- 调整粒子系统的`shapeModule.angle`

**Q: 想要烟雾有香味？**
A: 可以添加音效：
```csharp
// 在IncenseSmokeEffect.cs中添加
public AudioClip ambienceSound; // 环境音效
private AudioSource audioSource;

void Start()
{
    audioSource = gameObject.AddComponent<AudioSource>();
    audioSource.clip = ambienceSound;
    audioSource.loop = true;
    audioSource.Play();
}
```
