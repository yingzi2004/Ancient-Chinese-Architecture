# 导游对话系统使用说明

## 系统概述
这个系统用于在VR场馆中实现导游式对话，当玩家进入特定场景时，会在屏幕下方显示带立绘的导游对话。

## 文件说明

### 核心脚本
1. **GuideDialogueUI.cs** - 导游对话UI控制器
   - 显示对话面板
   - 处理打字机效果
   - 管理对话序列

2. **SceneGuideTrigger.cs** - 场景触发器
   - 检测玩家进入场景
   - 自动触发导游对话
   - 支持只触发一次

3. **GuideDialogueData.cs** - 对话数据文件
   - ScriptableObject数据容器
   - 可创建多个对话配置
   - 内置示例对话生成器

### 编辑器工具
4. **GuideDialogueSetupWindow.cs** - UI面板生成器
   - 自动创建导游对话UI
   - 自动绑定所有组件
   - 一键完成面板设置

## 快速开始

### 第一步：创建UI面板
1. 在Unity菜单栏选择：`Tools > 导游对话系统 > 创建导游对话面板`
2. 点击"加载立绘图片"按钮，加载路径：`Assets/UIdesign/AIChat/立绘/1-1.png`
3. 点击"创建导游对话面板"按钮
4. 系统会自动创建完整的UI面板并绑定所有组件

### 第二步：创建对话数据
1. 在Project窗口右键：`Create > Game > 导游对话数据`
2. 命名为"MinExhibitionGuide"
3. 在Inspector中：
   - 右键点击数据文件
   - 选择"生成Min Exhibition示例对话"
   - 或者手动输入对话内容

### 第三步：设置场景触发器
1. 在"Min Exhibition"场景中创建空对象
2. 命名为"SceneGuideTrigger"
3. 添加SceneGuideTrigger组件
4. 配置：
   - Target Scene Name: "Min Exhibition"
   - Dialogue Data: 拖入刚才创建的对话数据文件
   - Trigger Delay: 1.0（延迟1秒触发）
   - Trigger Once: true（只触发一次）

### 第四步：测试
1. 运行游戏
2. 进入"Min Exhibition"场景
3. 等待1秒后，导游对话会自动显示

## UI布局说明

自动创建的UI面板包含以下元素：
- **GuideDialoguePanel** (屏幕下方)
  - PortraitImage (左上角，200x250) - 立绘图片
  - GuideNameText (顶部左侧) - 导游名称
  - DialogueText (中央) - 对话内容
  - ContinuePromptText (右下角) - 继续提示
  - ContinueButton (底部中央) - 继续按钮

## 手动设置（如果自动创建失败）

### 创建UI结构
1. 在Canvas下创建空对象"GuideDialoguePanel"
2. 设置RectTransform：
   - Anchor: Bottom
   - Pos Y: 50
   - Width: Screen Width - 100
   - Height: 300
3. 添加Image组件（背景）

### 创建子对象
1. **PortraitImage** (立绘)
   - Type: Image
   - Anchor: Top-Left
   - Pos: (100, -100)
   - Size: (200, 250)

2. **GuideNameText** (导游名称)
   - Type: TextMeshPro
   - Anchor: Top-Left
   - Pos: (320, -50)
   - Font Size: 36
   - Color: White

3. **DialogueText** (对话内容)
   - Type: TextMeshPro
   - Anchor: Stretch
   - Pos: (100, 0)
   - Size: (-500, -200)
   - Font Size: 28
   - Alignment: Left-Top

4. **ContinuePromptText** (继续提示)
   - Type: TextMeshPro
   - Anchor: Bottom-Right
   - Pos: (-50, 50)
   - Font Size: 24
   - Color: Gray

5. **ContinueButton** (继续按钮)
   - Type: Button
   - Anchor: Bottom-Center
   - Pos: (0, 30)
   - Size: (200, 50)

### 添加脚本
1. 在GuideDialoguePanel上添加GuideDialogueUI脚本
2. 将所有UI组件拖拽到对应字段
3. 设置Typing Speed: 0.05
4. 设置Advance Key: L

## 对话操作

- **L键** - 推进对话
- **点击按钮** - 推进对话
- **打字中按L** - 立即完成打字

## 高级功能

### 多场景对话
为每个场景创建不同的对话数据文件：
- MinExhibitionGuide.asset
- FujianTulouGuide.asset
- SuzhouGardenGuide.asset

### 多个导游
使用不同的立绘图片：
- 1-1.png (导游1)
- 2-1.png (导游2)
- 3-1.png (导游3)

### 触发时机调整
- Trigger Delay: 调整触发延迟
- Trigger Once: 设为false可重复触发

## 常见问题

**Q: 对话不显示？**
- 检查GuideDialogueUI.Instance是否存在
- 确认UI面板已正确创建
- 检查场景名称是否正确

**Q: 立绘图片不显示？**
- 确认图片已正确加载
- 检查Sprite设置
- 确保图片Texture Type为Sprite (2D and UI)

**Q: 对话立即跳过？**
- 检查Trigger Delay设置
- 确认dialogueSequence不为空
- 查看Console是否有错误信息
