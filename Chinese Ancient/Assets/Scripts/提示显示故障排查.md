# 提示文字显示故障排查指南

## ❌ 问题：看不到提示文字

---

## 🔍 快速诊断方法

### 方法1：使用测试脚本（推荐）

1. **创建测试物体**
   ```
   在Unity中创建一个空GameObject或Cube
   命名为 "PromptTester"
   ```

2. **添加测试脚本**
   ```
   选中 PromptTester
   Add Component → 搜索 "InteractionPromptTester"
   ```

3. **运行游戏**
   ```
   如果能看到测试物体上的黄色提示框，说明OnGUI工作正常
   如果看不到，说明是其他问题
   ```

4. **检查Console**
   ```
   运行游戏后，按F1键（玉佩）或F2键（老爷爷）
   查看Console输出的坐标信息
   ```

---

### 方法2：检查基础设置

#### ✅ 检查1：确认脚本已正确添加

**玉佩对象**：
```
Inspector → 查看是否有 "JadePendant" 组件
✓ Can Be Picked Up = true
✓ Show Debug Info = true（开启调试）
```

**老爷爷对象**：
```
Inspector → 查看是否有 "GrandpaNPC" 组件
```

#### ✅ 检查2：确认玩家对象设置

```
玩家对象必须：
1. 有 "Player" 标签（Tag）
   或
2. 手动拖拽到玉佩和老爷爷的 Player Transform 字段
```

#### ✅ 检查3：确认距离

- **拾取范围**：3米内
- **交互范围**：3米内

在Scene视图中可以看到：
- 玉佩：黄色线框球 = 拾取范围
- 老爷爷：绿色线框球 = 交互范围

---

### 方法3：检查Canvas遮挡

OnGUI可能被Canvas UI遮挡。检查步骤：

1. **查找Canvas**
   ```
   Hierarchy窗口 → 搜索 "Canvas"
   ```

2. **检查Canvas设置**
   ```
   Canvas → Inspector → Canvas Scaler
   如果有Canvas，可能遮挡了OnGUI
   ```

3. **临时测试**
   ```
   选中所有Canvas对象
   取消勾选 Inspector 最顶部的 GameObject 激活框
   运行游戏看是否显示提示
   ```

---

### 方法4：启用调试信息

**玉佩脚本**：
```
Inspector → JadePendant组件 → Show Debug Info = 勾选
```

**老爷爷脚本**：
```
运行游戏后按 F2 键
查看Console输出的坐标信息
```

Console应该显示：
```
玉佩提示 - 屏幕坐标: (960, 540), 框位置: (840, 505)
老爷爷提示 - 屏幕坐标: (960, 400), 框位置: (820, 360)
```

如果看不到这些日志：
- 说明玩家没有被检测到
- 需要设置Player Transform

---

## 🛠️ 解决方案

### 解决方案1：手动设置玩家引用

**步骤**：

1. **选中玉佩对象**
   ```
   Inspector → JadePendant组件 → Player Transform
   拖拽你的玩家对象或Main Camera到这里
   ```

2. **选中秋老爷爷对象**
   ```
   Inspector → GrandpaNPC组件 → Player Transform
   拖拽你的玩家对象或Main Camera到这里
   ```

---

### 解决方案2：添加Player标签

**步骤**：

1. **选中玩家对象**
   ```
   可以是：
   - Main Camera
   - Player对象
   - VR Camera
   ```

2. **设置Tag**
   ```
   Inspector → 顶部 → Tag 下拉菜单
   选择 "Player"
   （如果没有，点击 "Add Tag..." 创建）
   ```

---

### 解决方案3：使用测试脚本确认

**步骤**：

1. **创建测试物体**
   ```
   Hierarchy → 右键 → Create Empty
   命名为 "TestPrompt"
   位置设置在 (0, 1, 0)
   ```

2. **添加测试脚本**
   ```
   选中 TestPrompt
   Add Component → Interaction Prompt Tester
   ```

3. **运行测试**
   ```
   Play → 如果看到 "按 [E] 拾取" 提示
   说明OnGUI工作正常
   ```

---

### 解决方案4：检查摄像机设置

**Main Camera设置**：
```
Inspector → Camera组件
✓ Depth = -1 或更低（确保是主相机）
✓ Clear Flags = Skybox
✓ Enabled = 勾选
```

---

## 📊 调试检查清单

在Unity编辑器中逐项检查：

### 场景设置
- [ ] Main Camera存在且启用
- [ ] 玩家对象有Player标签或已手动设置引用
- [ ] 玉佩和老爷爷在场景中

### 玉佩检查
- [ ] JadePendant脚本已添加
- [ ] Can Be Picked Up = true
- [ ] 有Collider组件
- [ ] Player Transform已设置（或Player标签）
- [ ] 距离玩家在3米内

### 老爷爷检查
- [ ] GrandpaNPC脚本已添加
- [ ] 有Collider组件
- [ ] Player Transform已设置（或Player标签）
- [ ] 距离玩家在3米内

### 摄像机检查
- [ ] Camera.main不为null
- [ ] 摄像机看向场景中的物体
- [ ] 物体在摄像机视野内

---

## 🔧 终极解决方案：使用3D文字

如果OnGUI仍然不工作，可以使用3D文字作为备选方案：

### 创建3D文字提示

**步骤**：

1. **创建文字对象**
   ```
   Hierarchy → 右键 → 3D Object → 3D Text
   命名为 "PickupPrompt"
   ```

2. **设置为玉佩的子物体**
   ```
   拖拽 PickupPrompt 到玉佩对象下
   Position: (0, 1, 0)
   ```

3. **设置文字内容**
   ```
   Text Mesh组件 → Text: "按E拾取"
   Font Size: 1
   Color: 黄色
   ```

4. **让文字始终朝向摄像机**
   ```
   添加脚本：
   ```csharp
   void Update() {
       transform.LookAt(Camera.main.transform);
   }
   ```

## 💡 快速测试命令

运行游戏时按以下按键查看调试信息：

- **F1键**：显示玉佩提示坐标
- **F2键**：显示老爷爷提示坐标

查看Console窗口的输出，确认：
- 屏幕坐标是否合理（0-1920, 0-1080）
- 物体是否在摄像机前方（z > 0）
- 框位置是否在屏幕内

---

## 📝 常见错误信息

### "Camera.main is null"
```
原因：场景中没有Main Camera标签的摄像机
解决：将主摄像机的Tag设置为"MainCamera"
```

### "Player is null"
```
原因：找不到玩家对象
解决：手动设置Player Transform或添加Player标签
```

### 提示位置在屏幕外
```
原因：物体在摄像机视野外
解决：移动玩家或物体到可见位置
```

## 📞 快速测试步骤总结

```
1. 运行游戏
2. 靠近玉佩
3. 按F1键查看Console
4. 如果有坐标输出但看不到提示
   → 可能是Canvas遮挡
5. 如果没有坐标输出
   → 玩家引用未设置
6. 添加测试脚本验证OnGUI
7. 根据结果应用相应解决方案
```
