## 🔧 解决方案2：使用3D文字（备选方案）

如果OnGUI仍然不显示，可以使用3D文字：

### 步骤1：添加SimplePromptTest组件

```
1. 选中玉佩对象
2. Add Component → 搜索 "Simple Prompt Test"
3. 勾选 Always Show（用于测试）
```

### 步骤2：调整3D文字位置

```
Inspector → Simple Prompt Test组件：
  Prompt Text: "按E拾取"
  Offset: (0, 2, 0)
  Font Size: 1
  Text Color: 黄色
```

### 效果
- 3D文字会显示在玉佩上方
- 文字始终朝向摄像机
- 不受Canvas遮挡影响

## 🔍 为什么OnGUI不显示？

最可能的原因：**Canvas UI遮挡了OnGUI**

### 快速验证方法

```
1. Hierarchy → 搜索 "Canvas"
2. 选中所有Canvas对象
3. 临时取消勾选（禁用）
4. 运行游戏
5. 如果看到了红色边框提示
   → 说明是Canvas遮挡问题
```

### 如何永久解决

如果确认是Canvas遮挡：

**方法1：调整Canvas渲染顺序**
```
选中Canvas → Inspector → Canvas组件：
  Sort Order: -1（让OnGUI在上层）
```

**方法2：使用Screen Space - Camera**
```
选中Canvas → Inspector → Canvas组件：
  Render Mode: Screen Space - Camera
  Render Camera: 拖拽Main Camera
```

**方法3：使用3D文字（推荐）**
```
使用SimplePromptTest组件
完全不受Canvas影响
```

## 🛠️ SimplePromptTest 组件说明

### 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| Prompt Text | "按E拾取" | 显示的文字 |
| Offset | (0, 2, 0) | 文字偏移位置（物体上方） |
| Text Color | 黄色 | 文字颜色 |
| Font Size | 1 | 字体大小 |
| Always Show | false | 是否始终显示（测试用） |

### 工作原理

- 检测JadePendant组件的状态
- 自动显示/隐藏提示文字
- 文字始终朝向摄像机
- 在3D空间中渲染，不受Canvas遮挡
