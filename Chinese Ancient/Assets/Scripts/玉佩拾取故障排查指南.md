## 快速修复步骤

### 第一步：在Unity编辑器中检查玉佩设置

1. **选中玉佩对象**
2. **在Inspector中查看JadePendant组件**，确认：
   - ✓ `Can Be Picked Up` = true
   - ✓ `Show Debug Info` = true（启用调试信息）
   - ✓ `Pickup Range` = 3（或合适的值）
   - ✓ `Allow Click Pickup` = true（启用鼠标拾取）
   - ✓ `Allow Keyboard Pickup` = true（启用E键拾取）

3. **检查Player Transform字段**：
   - 如果为空，脚本会自动查找Player标签的对象
   - 或者**手动拖拽**你的玩家对象/Camera到这个字段

### 第二步：设置玩家对象

**方法1：添加Player标签（推荐）**
1. 选中你的玩家对象或Main Camera
2. 在Inspector顶部，点击Tag下拉菜单
3. 选择 "Player"（如果没有，点击"Add Tag..."创建）

**方法2：手动指定玩家**
1. 选中玉佩对象
2. 在JadePendant组件的`Player Transform`字段
3. 拖拽你的玩家对象/Camera到这个字段

### 第三步：检查Collider

玉佩对象必须有Collider组件：
- Box Collider（推荐）
- Sphere Collider
- Capsule Collider

**注意**：
- 如果勾选了 `Is Trigger`，必须使用鼠标点击拾取
- 如果不勾选 `Is Trigger`，玩家会碰撞到玉佩

**脚本会自动添加**：
如果检测到没有Collider，脚本会自动添加一个BoxCollider（Trigger模式）

## 使用调试信息

### Game视图调试信息

运行游戏后，在Game视图左上角会显示：
```
玉佩调试信息:
ID: JadePendant_001
玩家距离: 2.50m / 3.00m
玩家对象: ✓
碰撞体: ✓
渲染器: ✓
```

**检查**：
- 如果 `玩家对象: ✗` → 需要设置Player Transform或添加Player标签
- 如果 `碰撞体: ✗` → 需要添加Collider组件
- 如果 `玩家距离` 显示为 `∞` → 玩家对象未正确设置

### Scene视图可视化

在Scene视图中选中玉佩，你会看到：
- **黄色线框球** = 拾取范围
- **绿色线** = 玩家在范围内
- **红色线** = 玩家在范围外

### Console日志

运行游戏时查看Console窗口：
```
[JadePendant] 玉佩初始化完成 - ID: JadePendant_001, 拾取范围: 3米
[JadePendant] 通过Player标签找到玩家对象
[JadePendant] 玩家在范围内 - 距离: 2.50米
✓ 成功拾取玉佩: JadePendant_001
```

## 常见问题解决

### ❌ 问题1：靠近玉佩但没有高亮

**原因**：玩家对象未正确设置

**解决**：
1. 确认玩家对象有 `Player` 标签
2. 或手动拖拽玩家到玉佩的 `Player Transform` 字段

---

### ❌ 问题2：看到提示但按E没反应

**原因**：输入被拦截或焦点问题

**解决**：
1. 点击Game视图确保焦点在游戏中
2. 尝试使用 **鼠标点击** 玉佩
3. 检查Console是否有错误信息

---

### ❌ 问题3：距离显示为∞

**原因**：玩家引用为null

**解决**：
1. 在Inspector中手动设置 `Player Transform`
2. 给玩家对象添加 `Player` 标签

---

### ❌ 问题4：拾取后任务没有更新

**原因**：任务管理器未找到

**解决**：
1. 确保场景中有 `JadePendantQuestManager` 对象
2. 检查Console日志确认任务管理器已找到
