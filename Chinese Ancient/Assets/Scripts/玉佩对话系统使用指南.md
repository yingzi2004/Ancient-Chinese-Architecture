# 玉佩任务对话系统使用指南

## ✅ 已完成功能

老爷爷NPC现在会在玩家归还玉佩后，自动触发一段感谢对话序列！

---

## 🎭 对话系统特性

### 1. 多句连续对话
老爷爷的感谢不是简单的一句话，而是一段连续的对话序列：
- 第一句：发现玉佩
- 第二句：表达感谢
- 第三句：讲述玉佩的背景
- 第四句：赞美玩家
- 第五句：给予奖励

### 2. 打字机效果
每句对话都会逐字显示，更有代入感

### 3. 按键继续
玩家按 **L** 键可以：
- 跳过当前打字效果
- 推进到下一句对话
- 结束对话

### 4. 锁定玩家移动
对话期间会锁定玩家移动，对话结束后自动解锁

## 📝 自定义对话内容

### 方法1：在Unity Inspector中编辑

1. 选中老爷爷对象
2. 在GrandpaNPC组件中找到 `Gratitude Dialogue Sequence`
3. 点击数组大小（默认5）
4. 在每个元素中输入对话内容

## 🎨 对话系统功能详解

### StartAutoDialogue 方法

```csharp
DialogueManager.Instance.StartAutoDialogue(
    npcName: "老爷爷",              // NPC名称
    dialogueSequence: new string[]  // 对话数组
    {
        "第一句对话",
        "第二句对话",
        // ... 更多对话
    },
    defaultPortrait: null,          // 可选：默认立绘
    expressionPortraits: null,      // 可选：表情差分
    onComplete: () =>               // 可选：完成回调
    {
        Debug.Log("对话结束");
    }
);
```

### 支持的功能

✅ **打字机效果** - 逐字显示文本
✅ **L键跳过** - 跳过当前打字
✅ **L键继续** - 推进到下一句
✅ **NPC名称** - 显示在对话框顶部
✅ **玩家锁定** - 对话期间锁定移动
✅ **自动解锁** - 对话结束自动解锁
✅ **完成回调** - 对话结束后执行自定义逻辑

## 🔧 故障排查

### 问题1：归还玉佩后没有对话

**检查**：
1. Console是否有错误信息？
2. DialogueManager是否存在？
3. gratitudeDialogueSequence是否为空？

**解决**：
```
确保场景中有DialogueManager对象
确保GrandpaNPC的Gratitude Dialogue Sequence有内容
```

---

### 问题2：按L键没反应

**检查**：
- 是否点击了Game视图（确保焦点在游戏中）
- 对话是否还在打字中

**解决**：
- 如果正在打字，按L会立即完成打字
- 再按一次L才会推进到下一句

---

### 问题3：对话结束后无法移动

**原因**：玩家控制器未正确解锁

**解决**：
检查DialogueManager是否正确引用了PlayerController

```csharp
// 在DialogueManager的Start()中会自动查找
playerController = FindObjectOfType<PlayerController>();
```

## 💡 进阶功能

### 1. 添加立绘图片

如果项目中有老爷爷的立绘，可以这样使用：

```csharp
private void StartGratitudeDialogue()
{
    if (DialogueManager.Instance != null)
    {
        Sprite defaultPortrait = Resources.Load<Sprite>("Portraits/Grandpa_Normal");
        Sprite[] expressions = new Sprite[]
        {
            Resources.Load<Sprite>("Portraits/Grandpa_Surprised"),  // 惊讶
            Resources.Load<Sprite>("Portraits/Grandpa_Happy"),      // 高兴
            Resources.Load<Sprite>("Portraits/Grandpa_Nostalgic"),  // 怀念
            Resources.Load<Sprite>("Portraits/Grandpa_Grateful"),   // 感激
            Resources.Load<Sprite>("Portraits/Grandpa_Smiling")     // 微笑
        };

        DialogueManager.Instance.StartAutoDialogue(
            npcName,
            gratitudeDialogueSequence,
            defaultPortrait: defaultPortrait,
            expressionPortraits: expressions,
            onComplete: () => Debug.Log("对话结束")
        );
    }
}
```

### 2. 修改打字速度

在DialogueManager的Inspector中：
```
Typing Speed: 0.05  (越小越快)
```

### 3. 修改继续键位

在DialogueManager的Inspector中：
```
Advance Key: L  (可以改为其他键)
```
