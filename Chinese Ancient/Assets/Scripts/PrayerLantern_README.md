# 祈福灯系统使用说明

## 系统简介

一个完整的祈福灯交互系统，允许玩家在祈年殿中写愿望、释放孔明灯，并查看其他玩家的祈福。

## 功能特点

✨ **核心功能**
- 玩家可以输入祈福内容和人名
- 选择灯笼颜色
- 释放祈福灯，看着它升空
- 自动生成其他玩家的祈福灯
- 点击空中的祈福灯查看详细内容
- 祈福数据自动保存到本地

✨ **视觉效果**
- 祈福灯缓缓升空
- 水平飘动效果
- 灯笼发光效果
- 平滑的淡出消失
- 多种颜色选择

✨ **交互设计**
- 靠近祈福点按F键打开祈福界面
- 快捷祝福按钮
- 点击空中祈福灯查看详情
- ESC键关闭界面

## 快速开始

### 方法1：使用自动设置工具（推荐）

1. 在Unity菜单栏选择：`GameObject → 祈福灯系统 → 自动设置`
2. 选择父对象（可选，留空则创建新对象）
3. 勾选需要创建的组件
4. 点击"自动设置系统"按钮

系统会自动创建：
- `PrayerLanternManager` - 管理器
- `PrayerLanternUI` - UI界面
- `LanternSpawnPoint` - 生成点

### 方法2：手动设置

1. **创建管理器**
   - 创建空对象，命名为"PrayerLanternManager"
   - 添加 `PrayerLanternManager` 组件
   - 设置生成点、预制体等参数

2. **创建UI**
   - 创建UI Canvas，命名为"PrayerLanternUI"
   - 添加 `PrayerLanternUI` 组件
   - 创建输入面板、按钮等UI元素
   - 关联到脚本引用

3. **创建生成点**
   - 创建空对象，命名为"LanternSpawnPoint"
   - 放置在合适的位置（如祈年殿前）
   - 关联到 Manager 的 Spawn Point

4. **创建祈福灯预制体**
   - 创建一个灯笼模型（可以是简单的立方体或Sphere）
   - 添加 `PrayerLantern` 组件
   - 添加 Light 组件（光源）
   - 添加 Renderer 组件（用于显示颜色）
   - 保存为预制体
   - 关联到 Manager 的 Lantern Prefab

## 脚本说明

### PrayerLanternManager
管理场景中所有祈福灯的生成、保存和显示

**主要参数：**
- `Lantern Prefab` - 祈福灯预制体
- `Spawn Point` - 生成位置
- `Max Lanterns` - 最大同时显示数量
- `Auto Spawn` - 是否自动生成
- `Auto Spawn Interval` - 自动生成间隔（秒）
- `Lantern Colors` - 可选的灯笼颜色数组

**公共方法：**
- `AddPrayer(wishText, playerName)` - 添加新祈福
- `SpawnLantern(data)` - 生成单个祈福灯
- `ShowLanternDetail(data)` - 显示祈福详情
- `ClearAllPrayers()` - 清除所有数据

### PrayerLantern
控制单个祈福灯的行为

**主要参数：**
- `Rise Speed` - 升空速度
- `Max Height` - 最大高度
- `Wander Range` - 水平飘动范围
- `Lantern Light` - 灯笼光源
- `Can Click To View` - 是否可点击查看

**公共方法：**
- `StartRising()` - 开始升空
- `ShowWishInfo()` - 显示祈福信息
- `SetData(data)` - 设置祈福数据

### PrayerLanternUI
处理祈福界面的显示和交互

**主要参数：**
- `Main Panel` - 主面板
- `Input Panel` - 输入面板
- `Wish Input Field` - 祈福内容输入框
- `Name Input Field` - 姓名输入框
- `Release Button` - 释放按钮
- `Quick Wish Buttons` - 快捷祝福按钮数组
- `Quick Wishes` - 快捷祝福内容

**公共方法：**
- `ShowUI()` - 显示UI
- `HideUI()` - 隐藏UI
- `ToggleUI()` - 切换UI显示状态

### PrayerLanternData
祈福灯数据类（序列化）

**属性：**
- `WishText` - 祈福内容
- `PlayerName` - 祈福人名称
- `CreateTime` - 创建时间
- `Position` - 位置
- `LanternColor` - 灯笼颜色

## 常见问题

**Q: 祈福灯不显示？**
- 检查预制体是否正确关联
- 检查生成点位置是否正确
- 查看Console是否有错误信息

**Q: 点击祈福灯没反应？**
- 检查祈福灯是否有Collider组件
- 检查距离设置是否过大
- 确保 `Can Click To View` 已勾选

**Q: 数据没有保存？**
- 检查是否在WebGL平台（WebGL不支持本地文件保存）
- 查看Console是否有保存成功的日志

**Q: UI不显示？**
- 检查Canvas的Render Mode设置
- 确保UI元素没有被禁用
- 检查EventSystem是否存在
