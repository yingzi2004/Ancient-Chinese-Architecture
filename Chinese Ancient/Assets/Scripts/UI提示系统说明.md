## 💡 交互逻辑

### 玉佩拾取
1. 玩家靠近玉佩（3米内）
2. 玉佩发光 + 显示提示框
3. 玩家按E键或点击
4. 拾取成功，提示消失

### 老爷爷交互
1. 玩家靠近老爷爷（3米内）
2. 根据状态显示不同提示：
   - 无玉佩：白色"按E对话"
   - 有玉佩：**金黄色"按E归还玉佩"**
   - 已完成：蓝色"按E对话"
3. 玩家按E键或点击
4. 触发相应对话或完成任务

## 📝 技术细节

### MakeTexture() 辅助函数
创建纯色纹理用于绘制背景和边框：
```csharp
private Texture2D MakeTexture(int width, int height, Color col)
{
    Color[] pix = new Color[width * height];
    for (int i = 0; i < pix.Length; i++)
        pix[i] = col;

    Texture2D result = new Texture2D(width, height);
    result.SetPixels(pix);
    result.Apply();
    return result;
}
```

### 3D到2D坐标转换
```csharp
Vector3 screenPos = cam.WorldToScreenPoint(transform.position + Vector3.up * offset);
screenPos.y = Screen.height - screenPos.y; // 翻转Y轴
```
