## 🎮 完整测试流程

### 步骤1：检查Unity设置

**玩家对象**：
```
选中玩家/Camera → Inspector → Tag → 选择"Player"
```

**玉佩对象**：
```
选中玉佩 → Inspector → JadePendant组件：
  ✓ Can Be Picked Up = true
  ✓ Allow Click Pickup = true
  ✓ Allow Keyboard Pickup = true
  ✓ Pickup Range = 3
```

**老爷爷对象**：
```
选中老爷爷 → Inspector → GrandpaNPC组件：
  ✓ Interaction Range = 3
  ✓ Allow Click Interaction = true
```

---

### 步骤2：运行测试

**1. 拾取玉佩**
- 靠近玉佩（3米内）
- 看到 "按 E 键拾取玉佩" 提示
- 按E键 或 点击玉佩
- ✅ Console显示: "拾取了玉佩: JadePendant_001"
- ✅ Console显示: "找到了玉佩！把它还给老爷爷吧！"

**2. 归还玉佩**
- 靠近老爷爷（3米内）
- 看到 "按 E 键归还玉佩" 提示
- 按E键 或 点击老爷爷
- ✅ Console显示: "任务完成：归还玉佩给老爷爷！"
- ✅ Console显示: "老爷爷: 谢谢你帮我找回了玉佩！你真是个好孩子！"
- ✅ Console显示: "【任务完成】寻找玉佩"

## 🔧 故障排查

### 问题1：看不到交互提示

**检查**：
1. 玩家对象是否设置了 `Player` 标签？
2. 是否在交互范围内？（默认3米）
3. Console是否有错误信息？

**解决**：
```
手动设置玩家引用：
选中玉佩 → Inspector → Player Transform → 拖拽玩家对象
选中老爷爷 → Inspector → Player Transform → 拖拽玩家对象
```

---

### 问题2：拾取了玉佩但老爷爷说没找到

**检查**：
1. PlayerPickup.Instance 是否存在？
2. 是否成功拾取玉佩？（看Console日志）

**测试方法**：
```csharp
// 在Console输入（如果有Debug Console）：
PlayerPickup.Instance.GetPendantCount()
// 应该返回 1
```

**解决**：
确保玩家对象上添加了 `PlayerPickup.cs` 脚本

---

### 问题3：老爷爷没有反应

**可能原因**：
1. 老爷爷没有Collider
2. Collider没有设置为Trigger
3. 距离太远

**解决**：
```
选中老爷爷 → Add Component → Sphere Collider
✓ Is Trigger = 勾选
✓ Radius = 1（或更大）
```
